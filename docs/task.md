# Почти готово

## Требования к приложению

1. Авторизация пользователя по логину и паролю;
2. Возможность указать аллергены, вегетарианство, веганство, диабет, без глютена, без лактозы, выбор стола по Познеру;
3. Ввод продуктов вручную с автодополнением;
4. Метрики блюда: стоимость докупки продуктов, порции, время, кбжу, аллергены;
5. Возможность фильтровать: аллергены, время, калорийность, можно приготовить в микроволновке, нужна плита, нужна духовка;
6. Рекомендации: лучшая одиночная покупка и план покупок под бюджет.
7. База из 100 рецептов и 150+ ингредиентов;
8. По клику на блюдо -- рецепт приготовления;
9. Возможность сохранить любимые блюда и ингредиенты;
