# AlmostDone REST API

Сервер приложения и база данных PostgreSQL развёрнуты на удалённой ВМ
по адресу <https://51.250.76.77>.

На этой же ВМ работает Grafana с метриками сервера:
<https://51.250.76.77/grafana/> (требуется вход).

Метрики собирает Prometheus каждые 15 секунд. В Grafana на дашборде
**AlmostDone API** доступны:

- Число запросов в секунду (RPS), суммарно и по маршрутам API.
- Время ответа: p50, p95 и p99 — время, в которое укладываются
  соответственно 50%, 95% и 99% запросов; p95 также показана по маршрутам.
- Ответы по HTTP-кодам, доля серверных ошибок 5xx и ошибки по маршрутам.
- Количество запросов, обрабатываемых в данный момент.
- Использование CPU и оперативной памяти процессом API.
- Доступность сбора метрик.

## Подключение к локальному стенду

Для другого стенда передайте `-PalmostReadyApiBaseUrl=https://api.example.org`
или задайте свойство в `~/.gradle/gradle.properties`. Указывайте Base URL без
`/api/v1`: клиент добавляет префикс сам.

Для локальной отладки API должен быть запущен на компьютере на порту `8000`.
Подключите телефон по USB и выполните `adb reverse tcp:8000 tcp:8000`.
Соберите debug-версию Android из каталога `mobile`:

```bash
./gradlew :app:assembleDebug -PalmostReadyApiBaseUrl=http://127.0.0.1:8000
```

Для своего экземпляра сервера укажите в `ALMOSTDONE_YANDEX_CLIENT_ID`
публичный Client ID Android из `mobile/app/build.gradle.kts`.
