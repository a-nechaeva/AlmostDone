# Почти готово · AlmostDone

Мобильное приложение, которое помогает выбрать, что приготовить из продуктов дома.
Оно подбирает доступные блюда и варианты, для которых нужно докупить 1–3 ингредиента,
показывает недостающие продукты, примерную стоимость покупки, время, КБЖУ и аллергены.
Первая платформа — Android; iOS рассматривается позже.

## Как это работает

1. Пользователь добавляет продукты, которые есть дома.
2. Приложение предлагает блюда, доступные сейчас, и варианты с небольшой докупкой.
3. Из списка или графа связей можно открыть рецепт: состав, порции, шаги
   приготовления, время, КБЖУ, аллергены и стоимость недостающих продуктов.
4. Рекомендации помогают выбрать одну полезную покупку или составить план под бюджет.

## Планируемые возможности

| Раздел | Возможности |
| --- | --- |
| Вход | Авторизация по логину и паролю |
| Продукты дома | Ручной ввод с автодополнением, изменение количества и удаление |
| Подбор блюд | Можно приготовить сейчас или докупить 1–3 ингредиента; граф связей продуктов, покупок и блюд |
| Рецепт | Пошаговое приготовление, порции, время, калории, белки, жиры, углеводы, аллергены и примерная стоимость докупки |
| Фильтры | Аллергены, время, калорийность, возможность готовить в микроволновке, необходимость плиты или духовки |
| Питание | Аллергены, вегетарианство, веганство, диабет, ограничения глютена и лактозы, диетический стол |
| Покупки | Лучшая одиночная покупка и план покупок под заданный бюджет |
| Избранное | Любимые блюда и ингредиенты |
| Скрытые блюда | Нежелательные по выбранным ограничениям блюда с объяснениями и предупреждениями |

Целевой каталог по требованиям — 100 рецептов и 150+ ингредиентов.
В макетах также проработаны список покупок и добавление продуктов по фото чека
с подтверждением распознанных позиций.

Правила медицинских ограничений и диетических столов, источники цен и КБЖУ
нужно согласовать до интеграции.
