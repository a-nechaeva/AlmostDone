
# Почти готово · AlmostDone

«Почти готово» помогает выбрать, что приготовить из продуктов, которые уже есть дома.
Приложение показывает блюда, доступные сейчас, и варианты, для которых нужно
докупить 1–3 ингредиента.

В Android- и iOS-клиентах есть запасы, подбор с фильтрами и графом покупок,
рецепты с порциями, шагами и КБЖУ, список покупок с лучшей одиночной
покупкой и планом под заданный бюджет, избранное, скрытые блюда
с объяснением ограничений и настройки питания. В серверном режиме
пользователи входят через Яндекс ID. Можно
распознать продукты на фото или чеке, проверить результат и подтвердить
добавление в запасы. Для распознавания нужна соответствующая настройка сервера.

## Сборка и запуск

### iOS

На macOS установите Xcode 26.2 с платформой iOS и средой выполнения
iOS Simulator. Из корня репозитория откройте проект:

```bash
open ios/AlmostReady/AlmostReady.xcodeproj

```

В Xcode выберите схему `AlmostReady`, симулятор iPhone и нажмите **Run**.
Чистый checkout запускается с демоданными. Команда сборки, серверный режим
и настройка подписи описаны в [инструкции iOS](ios/README.md).

### Android

Нужны JDK 21, Android SDK Platform 36 и Android Studio для запуска из IDE.
Откройте в Android Studio каталог `mobile/`, выберите конфигурацию `app`
и устройство или эмулятор с Android 7.0 (API 24) или новее. Для сборки из
терминала выполните из корня репозитория:

```bash
cd mobile
./gradlew :app:assembleDebug

```

APK появится в `mobile/app/build/outputs/apk/debug/app-debug.apk`.
По умолчанию приложение подключается к общему стенду и предлагает вход через
Яндекс ID. Настройка SDK и сборка для другого стенда описаны в [инструкции Android](mobile/README.md).

## Рабочий стенд

Серверная часть приложения развёрнута на удалённой ВМ с IP-адресом `51.250.76.77`.

### Сервер

В серверном режиме приложения обращаются к REST API. Документация API на
стенде — <https://51.250.76.77/docs>, проверка готовности —
<https://51.250.76.77/api/v1/health/ready>. На той же ВМ работает
[Grafana с метриками сервера](https://51.250.76.77/grafana/) (требуется вход).
[Контракт OpenAPI](docs/api/openapi.yaml) описывает запросы и ответы.
Подключение к локальному стенду и мониторинг описаны в [README сервера](server/README.md),
автодеплой на ВМ — в [README деплоя](deploy/README.md).
