# База данных

PostgreSQL хранит каталог, пользователей, их данные и серверные сессии.

| Файл | Назначение |
| --- | --- |
| `schema.sql` | Создание новой БД без данных |
| `seed.sql` | Дамп каталога; после загрузки требуется миграция |
| `migrations/001_server_state.sql` | Добавление таблиц сессий и серверного состояния в существующую БД |

## Миграция

`001_server_state` применяется один раз перед запуском обновлённого сервера.
Из корня репозитория, от владельца схемы или администратора БД:

```sh
psql --dbname "postgresql://USER:PASSWORD@HOST:5432/DATABASE" -v ON_ERROR_STOP=1 -f db/migrations/001_server_state.sql
```

Замените параметры подключения своими. При создании БД через актуальный
`schema.sql` миграция уже включена. Роли сервера нужны права на новые таблицы
и последовательность `user_identities_id_seq`.

## Таблицы серверного состояния

| Таблица | Назначение |
| --- | --- |
| `user_identities` | Привязки пользователей к внешним провайдерам входа |
| `auth_sessions` | Сессии пользователей и их отзыв |
| `auth_tokens` | Хеши токенов, сроки действия и история refresh |
| `user_api_state` | Версии состояния, дополнительные настройки и единицы количества |
| `api_idempotency` | Результаты запросов для безопасного повтора |
| `api_resources` | Снимки подбора, курсоры и результаты распознавания |
| `recognition_imports` | Отметки выполненного импорта чека |
| `api_schema_migrations` | Журнал применённых миграций |
